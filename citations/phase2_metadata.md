Generated by `scripts/analyze_phase2.py` from `data/openalex/citing_works.jsonl` (2,509 unique citing works pulled 2026-05-24). See [`citations/README.md`](README.md) for the broader plan and the per-year OpenAlex vs CZ Software Mentions table.

### What jumps out

- **Adoption is broad and global.** 9,196 unique authors across 2,395 ROR-distinct institutions in 127 countries; top by paper count is CN (900 papers, 35.9% of corpus).
- **Mycology is the single largest user community.** "Plant Pathogens and Fungal Diseases" is the top OpenAlex topic (581 papers, 23.2% of corpus); the #1 venue is "MycoKeys" (118 papers). Fungal taxonomy / plant pathogen work dominates the top-10 topics and the top-25 journals.
- **The OA share is high enough that Phase 3 (full-text acquisition) is feasible.** OA share climbs from ~50% in the mid-2010s to **~75% across 2021–2026** (see table below). Unpaywall + Europe PMC should reach the great majority.
- **There is a clear set of repeat users to contact.** Top 20 named authors each appear on 19–64 papers; 6,271 of 9,196 authors (68.2%) carry ORCIDs, so reaching them is tractable.

## Reproducing this digest

```sh
cd citations
uv run scripts/analyze_phase2.py
```

Reads `data/openalex/citing_works.jsonl` (built by `scripts/build_citing_works.py` from `data/openalex/raw/page_*.json`). Writes this file (`phase2_metadata.md`) and the flat `data/openalex/citing_works.csv`. Pure stdlib — no extra deps beyond the ones already in `pyproject.toml`.
